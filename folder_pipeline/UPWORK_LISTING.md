## Short pitch (2–3 sentences)

I build a small, offline Python tool that watches a folder for invoices or data files, pulls vendor / invoice number / amount into a clean CSV + SQLite database, skips files already processed (safe after a crash), and quarantines junk. You get a zip you can run on your PC — not a heavy custom “AI house.” Optional: scheduled Windows task so it runs while you work.
